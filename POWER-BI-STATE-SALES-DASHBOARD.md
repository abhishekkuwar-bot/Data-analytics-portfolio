# Power BI State Sales Dashboard

## Project Overview

An interactive Power BI dashboard designed to analyze sales performance across Indian states, regions, years and quarters.

## Objective

To analyze sales and quantity performance and identify high-performing states, regions and periods.

## Tools Used

- Microsoft Power BI
- Excel
- Data Visualization
- Power BI Slicers & Interactive Filters

## Key KPIs

- Total Sales
- Total Quantity
- Average Sales
- Maximum Sales
- Minimum Sales
- Target Sales

## Analysis Included

- Sales Amount by State
- Sales Amount by Region
- Quantity by State
- Quantity by Region
- Sales by Year
- Sales by Quarter
- Top 3 States by Sales
- Bottom 3 States by Sales
- Top 3 States by Quantity
- Bottom 3 States by Quantity

## Dashboard Features

- Interactive State filter
- Region filter
- Year and Quarter analysis
- Geographic sales visualization
- KPI cards
- Comparative charts
- Trend analysis

## Project Outcome

The dashboard provides an interactive view of sales performance and helps identify regional and state-level trends for business decision-making.

## Portfolio Note

This project demonstrates practical Power BI dashboard development, data visualization and business-oriented data analysis.
