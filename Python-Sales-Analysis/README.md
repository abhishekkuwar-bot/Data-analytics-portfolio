# Python Sales Analysis

## Project Overview

A practical Python-based Sales Analysis project designed to analyze sales performance, product performance, regional performance, and key business metrics.

## Objectives

- Calculate total sales and total quantity
- Calculate average sales and highest single sale
- Analyze sales by product
- Analyze sales by region
- Calculate regional sales contribution
- Analyze monthly sales trends
- Create data visualization using Python

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Anaconda
- VS Code
- GitHub

## Key Analysis

### Key Performance Indicators

The project calculates:

- Total Sales
- Total Quantity
- Average Sale
- Highest Single Sale

### Product Analysis

Sales are analyzed by product category to identify the strongest-performing products.

### Regional Analysis

Sales are grouped by region to compare regional performance.

### Regional Contribution

The project calculates each region's percentage contribution to total sales.

### Monthly Sales Trend

Sales are analyzed by month and visualized using a line chart.

## Visualizations

- Sales by Product — Bar Chart
- Sales by Region — Bar Chart
- Monthly Sales Trend — Line Chart
